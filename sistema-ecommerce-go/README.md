## Objetivo del Programa
Desarrollar un sistema de servicios web (API REST) en Golang, aplicando los fundamentos de programación orientada a objetos, encapsulación, interfaces y manejo de errores.

## Funcionalidades (8 Servicios Web)
1. `GET /` - Estado del servidor.
2. `GET /productos` - Listar inventario.
3. `POST /productos/crear` - Registro de productos.
4. `GET /clientes` - Listar clientes.
5. `POST /clientes/crear` - Registro de clientes.
6. `GET /pedidos` - Auditoría de pedidos.
7. `POST /pedidos/crear` - Procesar compras.
8. `PUT /stock/actualizar` - Gestión de inventario.

## Tecnologías Implementadas
* **Lenguaje:** Golang
* **Formato:** JSON
* **Protocolo:** HTTP
